# Painted mission backgrounds

Drop one image per mission here, named after the mission id:

| File name | Mission | Location |
|---|---|---|
| `battery.jpg` | 01 Battery Recovery | Underground power vault |
| `circuit.jpg` | 02 Circuit Restoration | Micro-fabrication cleanroom |
| `code.jpg` | 03 Code Debugging | Server mainframe hall |
| `comms.jpg` | 04 Communication Override | Rainy neon rooftop |
| `shutdown.jpg` | 05 Emergency Shutdown | Fusion reactor chamber |

`.webp`, `.jpg`, `.jpeg` and `.png` all work. Use a 16:9 image at least 1600 px wide, with no
characters, text or UI in it: Tek, the part, sparks and the HUD are drawn on top by the game.
Keep the lower third fairly simple (the workbench sits there) and the left third calmer (the HUD
sits there).

A mission without a file falls back to its built-in SVG background, so you can add these one at a
time. Only use images you have the rights to.
